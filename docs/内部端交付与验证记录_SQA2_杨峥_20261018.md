## 联调发现与修复

以下为修正既有契约实现，没有新增 REST 路径或修改数据库 schema。

1. `/me/borrows` 原来只查询 `borrows` 表，导致申请人在审核前或被驳回后看不到记录。现在同一标准分页中合并本人的 pending/rejected 请求和实际借阅；批准后的申请只展示对应借阅，保持本人隔离与分页总数正确。
2. 到期扫描原来以“今天减三个工作日”比较，导致远期图书提前提醒；现在以每条借阅的应还日期减三个工作日计算窗口。
3. 原来待到期后又逾期 30 天才生成违规候选；现在超过应还日期进入候选队列，默认 30 个自然日借期后及时提示图书管理教师；候选仍须人工沟通确认，记录不提供删除。
4. 帮助中“照片检测不阻断保存”的说明不符合必检规则，已更正为大小/可读性/比例必检，背景与着装仅建议。

前端还处理了二进制错误响应、401 会话清理、422 字段提示、服务器核验失败重试、签出失败保留会话和安全站内跳转。完整档案不写入 localStorage；文件 token 不放入 URL。

## 展示与统稿交接

1. 学生登录签到，查询并申请一本可借图书，展示待审记录。
2. 图书管理教师批准登记借出；学生刷新查看借阅、到期标记和站内提醒。
3. 下载专区展示八类栏目并下载；帮助展示在线阅读与索引。
4. 图书管理教师登记归还，说明 5 个自然日冷却、无续借、违规先确认后记录和超过 3 次停借；展示上限可配置。
5. 管理员展示教师/学生维护、CSV/XLSX 失败行、内容维护、照片检测和备份。恢复覆盖操作须使用独立演示库。
6. 所长与全职教师分别展示统计范围，最后退出签出。

正式评审：建议陈彬按 R3/R4 检查表组织走查、记录真实参与人、结论和跟踪项；本次未代填批准签字。AI 台账已在仓库及本地工作区追加，新增 `@playwright/test` 仅用于开发测试，沿用框架的开源登记由最终声明统一汇总。

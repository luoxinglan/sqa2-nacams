# 接口规范 v0.1（草案）· SQA2 网络攻防对抗技术研究所管理系统

> **定位**：前后端协作契约草案，由组长（ZCode 辅助）按需求框架 V3.3.1 与合同验收指标起草。
> **流程**：韦政治今晚（10-16）在此稿上细化定稿 → **10-17 12:00 冻结**（合同 M3 起点）→ 冻结后任何改动须群里提出并更新版本号，禁止私改。
> **技术栈无关**：REST over HTTP + JSON，Spring Boot 或 Flask 均适用；技术栈今晚定了以后，由韦政治补部署地址并转成正式接口文档（OpenAPI 或同格式 md 均可）。

## 1. 通用约定（全接口必须遵守）

| 项 | 约定 |
|---|---|
| 基础路径 | `/api/v1`（前端只经 API 取数，**禁止直连数据库**） |
| 数据格式 | 请求/响应均为 UTF-8 JSON；文件上传用 multipart/form-data |
| 认证 | 登录返回 token，后续请求带 `Authorization: Bearer <token>`；**登录即自动签到、登出（logout）即自动签出**（A-03） |
| 角色 | `guest`（未登录，仅公开接口）/ `user`（注册用户）/ `admin`（系统管理员）；所长、图书管理教师=管理员在用户上设置的标记位 `isDirector` / `isLibrarian`（管理员按业务指定，3.5.A-9 口径） |
| 时间格式 | 一律 `"YYYY-MM-DD HH:mm"`（24 小时制，到分钟，与合同口径一致）；纯日期 `"YYYY-MM-DD"` |
| 统一响应包 | `{"code": 0, "message": "success", "data": ...}`；`code=0` 成功，非 0 失败 |
| 分页 | 请求 `?page=1&page_size=20`；响应 `data = {"items": [...], "total": 123, "page": 1, "page_size": 20}` |
| 字段校验错误 | `code=422`，`data={"fields": {"字段名": "错误原因", ...}}`——前端据此在表单上逐字段提示 |
| 主要错误码 | 0 成功；400 参数错误；401 未登录；403 无权限；404 不存在；409 业务冲突（如超过在借上限，`message` 写明规则）；422 字段校验失败；500 服务器错误 |
| 隐私脱敏（B-07） | 服务端按角色输出字段：**游客/公开页可见=学号、姓名、邮箱、照片**；**电话、出生日期=仅本人和管理员可见**（列表接口对无权角色直接不返回该字段，前端不做"隐藏但传输"） |

## 2. 接口分工矩阵（谁提供、谁消费）

| 模块 | 提供方（后端） | 消费方（前端） |
|---|---|---|
| 认证账号、用户管理、批量导入、统计、内容管理 CRUD、媒体上传、备份恢复 | **韦政治** | 杨峥（管理员端）、刘罡甫/钟坤宇（公开页） |
| 图书借阅全流程、借阅配置、诚信记录、站内提醒、下载专区 | **陈彬** | 杨峥（注册用户端+管理员端） |
| 校验引擎、照片检测 | **陈彬**（校验规则同时做成后端共享库，韦政治在保存/导入路径调用） | 全部前端（表单预校验） |
| 首页聚合、门户内容查询 | **韦政治** | 刘罡甫（首页/登录页/简介）、钟坤宇（门户栏目） |

> 后端仓库内部建议：`backend/` 单仓库分模块（`auth/` `portal/` `library/` `admin/` `validation/` `backup/`），韦政治管框架与数据库（schema 变更权归韦政治），陈彬管 `library/` 与 `validation/`。

## 3. 接口明细（模块 × 方法 路径 ［权限］ 说明）

### 3.1 认证与账号（杨峥 UI ｜韦政治 BE）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| POST `/auth/login` | 公开 | `{username, password}` → `{token, user}`；登录即签到（记登录时间） |
| POST `/auth/logout` | user | 登出即签出（记登出时间） |
| GET `/auth/me` | user | 当前用户信息（含 isDirector/isLibrarian） |
| PUT `/me/profile` | user | 修改本人可改信息（敏感字段校验同 B 组规则） |

### 3.2 首页与门户内容（刘罡甫、钟坤宇 UI ｜韦政治 BE）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| GET `/site/info` | 公开 | LOGO、中英文名、版权、外链（cs/grd/gms.bit.edu.cn）——登录页 C-03 标志也用此接口 |
| GET `/home/summary` | 公开 | 首页聚合：最新动态×5＋通知数量（动态实时更新） |
| GET `/news?category=&page=` | 公开 | category=新闻动态/通知通告/学术活动；带撰稿人、发稿时间 |
| GET `/news/{id}` | 公开 | 详情＋图片/流媒体/附件列表（附件可下载） |
| GET `/about` | 公开 | 研究所简介、联系我们 |
| GET `/teachers?type=全职\|兼职` | 公开 | 师资列表（按 B-07 脱敏） |
| GET `/teachers/{id}` | 公开 | 详情：职称、导师资格、职务、社会兼职等公开字段 |
| GET `/students?status=在读\|毕业&year=&page=` | 公开 | 学生列表（按 B-07 脱敏；在读按年份展示照片） |
| GET `/achievements?type=&page=` | 公开 | type=教学成果/教学论文/教材/教改/科研成果/科研论文/专利/著作权（8 枚举），表格数据 |
| GET `/courses`、`/projects` | 公开 | 教学科研：课程信息、项目信息 |
| GET `/admissions?level=` | 公开 | level=本科/硕士/博士/留学生 |
| GET `/cooperations` | 公开 | 国际合作表格 |

### 3.3 图书借阅（杨峥 UI ｜陈彬 BE，规则=需求 §3.2.1.2.2）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| GET `/books?keyword=&page=` | user | 图书目录（编号 7 位=购买年份 4+顺序 3；基础数据 B001 风格由导入脚本换算） |
| POST `/books/{id}/borrow-requests` | user | 发起借阅；后端强制校验：同一图书仅一本、在借上限（默认 2，可配置）、违规≥3 次停借、归还 5 天内不可再借 |
| GET `/me/borrows` | user | 我的借阅：状态、应还日期、剩余天数、到期提醒标记 |
| GET `/admin/borrow-requests?status=` | librarian | 待审核借阅请求 |
| POST `/admin/borrow-requests/{id}/approve` \| `/reject` | librarian | 审核登记后借出/驳回 |
| GET/PUT `/admin/library/config` | librarian | `{maxBorrow:2, loanDays:30, remindBeforeWorkdays:3}`——上限可由图书管理教师设置（F-03 可配置参数） |
| GET `/admin/violations?userId=&page=` | admin | 诚信记录（**只增不删**——需求口径不可清除） |
| POST `/admin/violations` | admin | 确认记录违规 1 次（超 30 天未还，先管理员确认再记录）；**不提供 DELETE** |
| POST `/admin/books`、`/admin/books/import` | admin | 图书新增/批量导入 |

### 3.4 下载专区与站内提醒（杨峥 UI ｜陈彬 BE）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| GET `/downloads?category=&page=` | user | 8 类：开题/中期/答辩/学位论文/专利/会议/上级文件/其他 |
| GET `/downloads/{id}/file` | user | 文件下载（流/302） |
| GET `/notifications` | user | 站内提醒列表（图书到期提醒=期满前 3 个工作日自动产生，发借阅人与管理教师） |
| PUT `/notifications/{id}/read` | user | 标记已读 |

### 3.5 用户管理与统计（杨峥 UI ｜韦政治 BE）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| GET `/admin/users?keyword=&role=&page=` ｜ POST/PUT/DELETE `/admin/users[/{id}]` | admin | 注册用户增删改查；含设置 isDirector/isLibrarian |
| POST `/admin/users/import` | admin | Excel/CSV 批量导入（A-07）；判重键=学号/工号；响应=行级结果 `{row, ok, reason}`（"由开发方自行设计"口径） |
| GET `/stats/signin?scope=all\|mine` | director（all）/教师（mine） | 签到签出统计：所长看全员、全职教师看本人名下学生 |

### 3.6 内容管理（杨峥 admin UI ｜韦政治 BE；数据供钟坤宇公开页展示）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| POST/PUT/DELETE `/admin/content/{type}` | admin | type=news/achievements/courses/projects/admissions/cooperations/about；成果支持单条录入与 Excel/CSV 导入 |
| POST `/admin/media` | admin | 图片/附件/流媒体上传，返回 URL |

### 3.7 校验与照片检测（全前端 ｜陈彬 BE=唯一权威）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| POST `/validate` | user/admin | `{type: "teacher"\|"student", fields: {...}}` → 422 结构化字段错误；规则=工号 B-02（10 位，61201/72201/74201）、学号 B-03（10 位编码规则）、姓名 B-04（姓名登记条例；留学生豁免标记 `nameExempt` 跳过校验）、电话 B-06（移动 11 位+国家代码可选；办公 3 位区号+8 位）。**后端保存/导入路径强制同规则**（前端校验仅为体验） |
| POST `/photos/check` | user/admin | multipart；**必检**：≤2MB、宽高比 33:48；**提示性**：背景色/着装建议；返回 `{sizeOk, ratioOk, suggestions[]}`（B-05） |

### 3.8 数据备份与恢复（韦政治 BE ｜D-01/D-02）
| 方法 路径 | 权限 | 说明 |
|---|---|---|
| POST `/admin/backup` | admin | 立即备份 → `{fileName, size, createdAt}` |
| GET `/admin/backups` | admin | 备份列表（含备份周期与存放位置说明，验收 D-01 要求） |
| POST `/admin/restore` | admin | 上传备份文件恢复（恢复演练用，操作需二次确认） |
